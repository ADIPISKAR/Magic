# SEO Magic — рабочая версия

Операционная инструкция для этого сайта: [scripts/README.md](scripts/README.md).
Карта страниц и оставшиеся действия: [MAGIC-SEO-PLAN.md](MAGIC-SEO-PLAN.md).

`SEO-Playbook.docx`, `Checklist-zapuska.docx` и `growth-chart.html` — исходные
референсы кейса другого сайта, не статистика Magic и не инструкция к запуску
новых скриптов. Перед использованием учитывайте поправки:

- Google Indexing API не поддерживает обычные страницы услуг ремонта.
- FAQ rich results прекращены с 7 мая 2026 года; FAQ на страницах нужен посетителю.
- lastmod должен отражать фактическое существенное изменение страницы.
- Статус Discovered — currently not indexed не доказывает недостаток ссылок.
- В референсном графике период/агрегация строк страниц не согласованы с общим итогом:
  517 / 649 = 79,66%, а не 85%; сумма приведённых страниц — 790. Без исходной
  выгрузки эти показатели нельзя использовать как единый проверенный отчёт.

Источники поправок, проверены 01.09.2026:

- [Google Indexing API](https://developers.google.com/search/apis/indexing-api/v3/quickstart)
- [Google Search: прекращение FAQ rich results](https://developers.google.com/search/updates#may-2026)
- [Правила sitemap и lastmod](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap)
- [Статусы индексации GSC](https://support.google.com/webmasters/answer/7440203)
