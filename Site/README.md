# «Магия» — сайт ремонтной компании

Коммерческий лендинг для компании по ремонту квартир в Ростове-на-Дону. Проект показывает полный цикл веб-разработки: адаптивный интерфейс, серверную обработку заявок, интеграцию с внешним API, SEO и оптимизацию загрузки изображений.

## Что реализовано

- адаптивная главная страница с портфолио, услугами, отзывами и формой заявки;
- серверная валидация заявок и безопасная передача данных в API Telegram-бота;
- конфигурация интеграций через переменные окружения;
- `sitemap.xml`, `robots.txt`, Open Graph и структурированные данные Schema.org;
- WebP-изображения, lazy loading, кеширование статики и HTTP security headers;
- production-сборка фронтенда через Vite;
- автоматические тесты основных HTTP-сценариев.

## Стек

- PHP 8.3, Laravel 13;
- JavaScript, Blade;
- Tailwind CSS 4 и Bootstrap 5;
- Swiper;
- Vite 8;
- PHPUnit.

## Локальный запуск

Понадобятся PHP 8.3+, Composer и Node.js.

```bash
git clone https://github.com/ADIPISKAR/Magic.git
cd Magic/Site
composer run setup
npm install
composer run dev
```

Приложение создаст локальный `.env` из безопасного шаблона `.env.example`. Для отправки заявок укажите собственные значения:

```dotenv
BOT_API_URL=
BOT_API_SECRET=
```

Не добавляйте `.env` в Git. Он уже исключён правилами `.gitignore`; в репозитории хранится только `.env.example` без секретов.

## Проверка

```bash
composer test
npm run build
```

## Структура

- `app/Http/Controllers/LeadController.php` — валидация и отправка заявок;
- `resources/views/welcome.blade.php` — разметка лендинга;
- `resources/js/app.js` — интерактивность и отправка формы;
- `resources/css/app.css` — стили интерфейса;
- `routes/` — веб- и API-маршруты;
- `tests/` — автоматические тесты.
- `config/seo_pages.php` — контент и даты обновления страниц услуг;
- `info/scripts/README.md` — настройка и запуск SEO-аудита и отчётов GSC;
- `info/MAGIC-SEO-PLAN.md` — карта запросов, проверенные данные и шаги публикации.

## Безопасность

Секреты и пароли не хранятся в исходном коде. Чувствительные настройки читаются из переменных окружения, а пример конфигурации содержит только пустые или демонстрационные значения. Перед публикацией история Git была дополнительно проверена на ключи, токены и приватные ключи.
